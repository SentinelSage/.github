## What this studio is (and is not)

**Is:** carefully scoped demos of protective ML/UX — scoring with limits, calibration and honesty over theater, portfolio-quality full stacks.

**Is not:** a production SOC, IDS, or ethics/compliance product; a True/False ministry; malware tooling; or a claim that model outputs should drive real containment or life-or-death decisions.

Reading each demo’s **Safety** / **Limits** (or equivalent) section before relying on outputs is part of using them responsibly.
